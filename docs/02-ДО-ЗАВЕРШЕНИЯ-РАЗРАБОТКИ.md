## Этап 5 — Marketplace/PDD (3–5 дней, требует решения владельца)

Блокирующее решение: **официальный доступ Pinduoduo Open Platform отсутствует**. Фактически интегрирован AliExpress DS API.

Вариант A (рекомендуется для MVP): зафиксировать AliExpress как marketplace-провайдер, переименовать PDD-потоки в `MarketplaceAdapter`.
Вариант B: получить доступ PDD API и реализовать `PddAdapter` по ТЗ §9–13.

В любом варианте:
- [ ] Абстракция `MarketplaceAdapter`: searchProducts/getProduct/getCategories/createOrder/getOrder/cancelOrder/getLogistics.
- [ ] `GET /integrations/marketplace/status` → `{configured, reachable, authenticated, provider, code}` (ТЗ §10).
- [ ] Маппинг ошибок `*_NOT_CONFIGURED / TIMEOUT / RATE_LIMIT / PROVIDER_ERROR / INVALID_RESPONSE` (ТЗ §11).
- [ ] Timeout 10s, max 2 retry, requestId, логирование без секретов (ТЗ §12).
- [ ] Кэш (Redis или `MarketplaceApiCache`): categories 1h, product 5–15 мин, search 1–5 мин, fallback на кэш при недоступности (ТЗ §13).
- [ ] Проверить маппинг полей `marketplaceSkuForOrder`/`freightOptions` на реальных ответах API (методы реализованы в аудите по документации, требуют калибровки).
